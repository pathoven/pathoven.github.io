## Project Snapshot

- Hardware: Raspberry Pi 5, Arduino-based motor controller, RPLidar A1/A2, camera
- Software: Ubuntu 24.04 + ROS2 Jazzy, Arduino firmware, Node.js control UI
- Capabilities: SLAM, manual teleoperation, autonomous waypoint navigation
