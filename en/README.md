# Welcome to the English Docs

The Pathoven Drive project documents how we built an autonomous 1/10 RC car powered by ROS2 Jazzy. The English section captures the same steps as our internal Turkish notes but polished for the open-source community.

## What You Will Find

- Step-by-step hardware assembly with wiring tips
- Full software stack: Ubuntu 24.04, ROS2 packages, Arduino firmware, Node.js dashboard
- Calibration workflows for steering, IMU, and LiDAR
- Testing checklists for each milestone
